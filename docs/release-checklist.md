# Skill 发布检查清单

发布或更新 Skill 前，逐项检查。

## 基础信息

- [ ] 目录名使用小写英文、数字和连字符。
- [ ] `README.md` 已说明用途、适用场景、安装方式和示例。
- [ ] `SKILL.md` 包含 `name` 和 `description`。
- [ ] `description` 说明“什么时候使用”，而不是罗列执行步骤。
- [ ] 仓库根目录的 Skill 列表已更新。

## 内容质量

- [ ] 一个 Skill 只聚焦一个明确场景。
- [ ] `SKILL.md` 足够精简，没有塞入长篇背景说明。
- [ ] 长说明、案例、规范已经移到 `references/`。
- [ ] 可重复操作已经尽量放入 `scripts/` 或清晰步骤。
- [ ] 示例提示语能代表真实使用场景。

## 公开发布

- [ ] 已删除账号、密钥、Cookie、邮箱、手机号等私人信息。
- [ ] 已删除本机专属路径，或改成通用说明。
- [ ] 已确认图片、模板、引用资料可以公开分享。
- [ ] 已说明依赖、限制和人工判断环节。
- [ ] 已确认许可证适合公开分享。

## 验证

- [ ] 用一个真实任务试运行过。
- [ ] 检查过输出是否符合预期。
- [ ] 如果包含脚本，已经运行过最小示例。
- [ ] 如果包含模板或素材，确认路径和文件名正确。
