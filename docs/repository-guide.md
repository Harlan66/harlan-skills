# Repository Guide

This guide is for maintaining the repository. It is not the public introduction.

## What belongs in this repository

- Repeatable personal workflows.
- Tested content production, research, writing, and publishing processes.
- Agent Skills for specific recurring tasks.
- Templates, references, and helper files that make a Skill easier to reuse.

Avoid adding one-off project notes, raw chat logs, private account details, secrets, or files that cannot be shared publicly.

## Documentation roles

- Root `README.md`: public introduction for GitHub visitors.
- Skill `README.md`: human-facing explanation for one Skill.
- `SKILL.md`: AI Agent-facing instructions.
- `references/`: long examples, rules, and supporting notes.
- `scripts/`: repeatable helper actions.
- `assets/`: templates and reusable files.

## Maintenance principles

- Keep each Skill focused on one clear use case.
- Keep `SKILL.md` concise.
- Put detailed background in `references/`.
- Remove private information before publishing.
- Test with a realistic task before sharing updates.
