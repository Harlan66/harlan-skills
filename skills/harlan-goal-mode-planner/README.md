# harlan-goal-mode-planner

把模糊目标整理成适合 Goal Mode 长时间执行的清晰目标。

## 适合什么时候用

- 需要把一个想法改写成可执行的 Goal。
- 需要诊断已有 Goal 是否太宽、太空或缺少边界。
- 需要为长期任务补充分阶段计划、验收标准和停止条件。
- 需要明确哪些判断应该由使用者确认。

## 你会得到什么

- 对现有目标的诊断。
- 更清晰的目标结构。
- 分阶段计划。
- 状态跟踪要求。
- 验收标准和停止条件。

## 使用方式

把整个 `harlan-goal-mode-planner` 文件夹复制到你的 AI 工具 Skills 目录中，然后提供你的目标草稿或模糊想法。

示例：

```text
请使用 harlan-goal-mode-planner，把这个目标整理成适合 Goal Mode 执行的版本。
```

## 目录说明

- `SKILL.md`：目标诊断和改写规则。
- `agents/openai.yaml`：展示信息。
