# harlan-gzh-pb

面向微信公众号文章的排版、配图和发布前检查 Skill。

这个 Skill 来自我在 WeMD 工作流中的真实使用经验，重点是保持原文不被改写，同时为文章增加稳定的视觉排版、配图节奏和发布前检查。

## 适合什么时候用

- 需要把中文长文整理成微信公众号排版稿。
- 需要保持原文不变，只做排版、强调和配图。
- 需要统一封面图和正文插图风格。
- 需要在复制到微信公众号前检查图片地址、样式和正文完整性。

## 你会得到什么

- 保留原文的微信公众号排版稿。
- 文章封面和正文插图规划。
- 深蓝知识型视觉风格规则。
- 发布前检查清单。

## 使用方式

把整个 `harlan-gzh-pb` 文件夹复制到你的 AI 工具 Skills 目录中。使用时提供文章原稿，并说明你希望按微信公众号排版处理。

示例：

```text
请使用 harlan-gzh-pb，把这篇文章整理成微信公众号排版稿，并给出配图方案。
```

## 目录说明

- `SKILL.md`：执行流程和排版规则。
- `references/current-style.md`：当前视觉风格、模块和图片规则。
- `agents/openai.yaml`：展示信息。

## 注意

这个 Skill 默认结合本地 WeMD 类工作流使用。不同项目可以复用排版和配图规则，但构建命令、预览地址和图片上传方式需要按自己的项目调整。
