# app-interaction-map

把 App 截图、录屏帧、页面列表、路由信息和接口线索整理成可靠的交互地图。

## 适合什么时候用

- 需要从截图或录屏还原 App 的页面结构。
- 需要给产品、设计、测试或研发整理交互流程。
- 需要把确认信息、推断信息和未知信息分开标注。
- 需要为 Figma、FigJam、Markdown 或表格交付做准备。

## 你会得到什么

- 清晰的页面清单。
- 主要流程和分支流程。
- 每个操作的入口、结果和跳转。
- 已确认、推断、未知内容的区分。
- 待补充截图和开放问题清单。

## 使用方式

把整个 `app-interaction-map` 文件夹复制到你的 AI 工具 Skills 目录中，然后在任务中提供截图、录屏帧、页面列表或相关说明。

示例：

```text
请使用 app-interaction-map，把这些 App 截图整理成一份交互地图。
```

## 目录说明

- `SKILL.md`：交互地图的执行规则。
- `references/output-template.md`：输出结构模板。
- `agents/openai.yaml`：展示信息。
